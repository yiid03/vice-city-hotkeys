## Vice City Hotkeys 1.0.0

A small Windows utility that types cheat codes for classic GTA Vice City when you tap a function key.

- Seven ready-to-use shortcuts for health, armor, weapons, wanted level, and a tank.
- Customizable F1–F12 keys and editable cheat codes.
- English and Turkish interfaces with a remembered language preference.
- Adjustable typing speed and cancellation when switching away from the game.
- Per-user setup with uninstall support, plus a portable archive.

### Downloads

- **ViceCityHotkeys-1.0.0-Setup.exe** — recommended installer.
- **ViceCityHotkeys-1.0.0-Portable.zip** — extract and run without installing.
- **SHA256SUMS.txt** — SHA-256 file checksums.

Requires Windows 10/11 and .NET Framework 4.8 or later. Supports the original PC version, with `gta-vc.exe` or `gta_vc.exe`; not the Definitive Edition.

The binaries are unsigned. Automated settings and interface tests pass; compatibility with a running copy of Vice City has not yet been verified.
